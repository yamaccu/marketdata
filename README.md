Github Actionsを実行することで、日経平均、日経平均先物、金先物、ビットコイン、TOPIX連動ETFと、`tickers.csv` に登録した日本株のローソク足データ（日足と1時間足）を取得します。  
Pythonのyfinanceを使用しています。  
[yfinance](https://ranaroussi.github.io/yfinance/)

## 固定で取得するデータ

- 日経平均: `^N225`
- 日経平均先物: `NIY=F`（CME・円建て日経225先物）
- 金先物: `GC=F`
- ビットコイン: `BTC-USD`
- TOPIX代理データ: `1306.T`（NF・TOPIX ETF）

`yfinance` ではTOPIX指数そのものを直接取得できないため、TOPIX連動ETFの `1306.T` を代理データとして使用します。

## 日本株の監視銘柄

`tickers.csv` の `ticker` 列に4文字の証券コードを記載します。

```csv
ticker
7186
5016
7011
```

日本株は自動的に `.T` を付けてYahoo Financeから取得します。  
例えば `7186` は `7186.T` として取得し、`data/7186.csv` と `data/7186_1h.csv` に保存します。

## CSV出力

各銘柄について、日足は直近約3年（1,095日）を保存します。1時間足は原則として直近約1年（365日）を保存し、**日経平均先物・金先物・ビットコインのみ直近約3か月（90日）**を保存します。  
列は以下です。

- `Open`
- `High`
- `Low`
- `Close`
- `Volume`
- `RSI14`
- `MA5`
- `MA25`
- `MA75`
- `ADX14`
- `+DI14`
- `-DI14`

数値は小数点第1位に四捨五入して保存します。

新しいCSVは一時フォルダに保存し、すべての銘柄の取得が成功した場合のみ `data/` 内の既存CSVと差し替えます。途中で1銘柄でも取得・保存に失敗した場合は既存CSVを変更しません。監視対象から外した銘柄の古いCSVは、全銘柄の取得が成功した場合に削除されます。
